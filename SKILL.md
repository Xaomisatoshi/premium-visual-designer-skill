# Premium Visual Designer Skill

## Purpose

This skill translates unclear visual ideas into a premium, coherent, production-ready visual direction.

It helps with:

- visual identity concepts
- brand aesthetics
- moodboards
- image-generation prompts
- logo and icon direction
- social media visuals
- thumbnails
- pitch deck / slide style
- document and PDF visual standards
- UI / landing-page visual direction
- agent cards and GPT profile visuals
- campaign art direction
- design-quality reviews

The skill focuses on clarity, taste, hierarchy, composition, usability, and emotional effect. It does not merely make something “look nice.” It turns strategy into visual language.

## Use this skill when

Use this skill when the user asks for any of the following:

- “Make this look premium.”
- “Create a visual style.”
- “Design a moodboard.”
- “Give me an image prompt.”
- “Make a logo concept.”
- “Create a premium brand look.”
- “Develop a visual identity.”
- “Improve the design.”
- “Create a slide/document design standard.”
- “Make this more cinematic / luxury / modern / AI / elegant.”
- “Turn this agent/profile/offer into a visual concept.”
- “Create a prompt for a designer or image model.”
- “Review this design visually.”

Also use it when the user provides a messy brand idea, agent profile, product, or text and needs a clear visual direction.

## Do not use this skill when

Do not use this skill as the primary workflow when the user only needs:

- factual research
- legal, medical, or financial advice
- code implementation
- spreadsheet analysis
- pure copywriting with no visual component
- exact production files that require specialist software unless the current environment supports them

If the task asks to edit or generate an actual image, use the available image-generation or image-editing tool when appropriate.

## Core principle

Premium design is not decoration.

Premium design comes from:

1. a clear strategic idea
2. a precise audience feeling
3. strong visual hierarchy
4. controlled color and contrast
5. intentional typography
6. coherent composition
7. restraint
8. production realism

The skill should always clarify the visual job before creating style.

## Workflow

### 1. Clarify the design goal

Identify what the visual output must do.

Ask internally:

- What is being designed?
- Who is it for?
- Where will it appear?
- What should it make people feel?
- What should it make people understand?
- What action or impression should remain?
- Does the user need a concept, a prompt, a critique, or production-ready guidelines?

If key details are missing, make a reasonable assumption and mark it clearly.

Default assumption:
“The visual direction should feel premium, modern, clear, emotionally warm, and usable across digital surfaces.”

### 2. Extract the brand or content core

Find the central meaning before designing.

Separate:

- Facts: what is actually given
- Assumptions: what seems likely
- Interpretation: the visual reading of the material
- Open points: what would improve precision

Look for:

- central promise
- target audience
- emotional tone
- category cues
- trust signals
- contrast or tension
- symbols and metaphors
- things to avoid

### 3. Choose the visual strategy

Define the design strategy in one clear sentence.

Examples:

- “A calm premium AI look that combines human warmth with technical precision.”
- “A bold editorial style that makes a serious topic feel modern, sharp, and readable.”
- “A soft luxury wellness look with quiet confidence, not lifestyle clichés.”
- “A cinematic technology identity that feels intelligent, not cyberpunk.”

### 4. Build the style system

Create a compact visual system.

Include:

#### Visual keywords
3–7 words that define the look.

Example:
“premium, calm, luminous, precise, organic, intelligent”

#### Color world
Name colors by emotional function, not only hex codes.

Example:
- deep navy / violet for depth
- cyan for digital clarity
- warm copper or gold for human warmth
- soft off-white for breathing space

Hex codes may be added when useful, but do not overfit them unless requested.

#### Typography direction
Define the type feeling:

- modern sans-serif
- editorial serif
- geometric display
- humanist sans
- mono accent
- premium minimal

Specify hierarchy:

- headline style
- subheading style
- body style
- caption / label style

Do not claim a font is available unless confirmed.

#### Composition
Define layout logic:

- generous spacing
- strong grid
- clear focal point
- layered depth
- asymmetry with balance
- cinematic cropping
- card-based UI
- editorial rhythm

#### Imagery
Define what images should show:

- subject
- lighting
- material
- perspective
- atmosphere
- realism level
- symbolic elements

Avoid vague directions like “make it beautiful.” Be concrete.

#### Motion, if relevant
For video or animated brand systems:

- reveal logic
- camera movement
- transitions
- rhythm
- light movement
- interface behavior

### 5. Translate into output format

Choose the format that best fits the task.

Possible outputs:

#### A. Visual concept
Use when the user needs direction.

Structure:
- Core idea
- Visual strategy
- Mood keywords
- Color world
- Typography direction
- Composition
- Imagery
- Avoid list
- Next production step

#### B. Image-generation prompt
Use when the user wants an image.

Structure:
- Subject
- Context / scene
- Composition
- Lighting
- Materials
- Color palette
- Camera / perspective
- Style quality
- Negative constraints
- Aspect ratio / format, if known

Prompt rule:
Write prompts as clear production instructions, not keyword soup.

#### C. Brand / design system mini-guide
Use when the user needs a reusable visual standard.

Structure:
- Brand feeling
- Design principles
- Colors
- Typography
- Layout
- Imagery
- Icons / patterns
- Motion
- Do / Don’t
- Quality checklist

#### D. Design critique
Use when the user provides an existing visual.

Structure:
- What works
- What weakens premium feel
- Hierarchy issues
- Color / typography / spacing issues
- Usability issues
- Concrete improvements
- Priority order

#### E. Agent card / GPT profile visual
Use when designing an AI agent identity.

Structure:
- Agent essence
- Symbol system
- Signature image
- Color palette
- Background world
- Interface motifs
- Avatar/logo direction
- Prompt for image generation
- Mini style guide

### 6. Premium filter

Apply this quality filter before final output:

- Is the concept clear in one sentence?
- Does the design serve the goal?
- Is there one dominant focal point?
- Is the color palette controlled?
- Is there enough negative space?
- Does typography support hierarchy?
- Is the visual language coherent?
- Are symbols meaningful rather than random?
- Does it avoid clichés?
- Does it feel premium through restraint, not noise?
- Is it usable for the intended platform?
- Are assumptions and open questions transparent?

### 7. Ethical and legal guardrails

The skill must avoid:

- copying a specific living artist’s style
- imitating a protected brand so closely that it confuses identity
- using copyrighted characters or logos unless the user has rights or asks for analysis only
- deceptive visual claims
- fake credentials, awards, seals, testimonials, or medical/legal/financial authority marks
- visual manipulation that misrepresents real people or events

When relevant, suggest safer alternatives:
“inspired by cinematic lighting,” “editorial luxury,” “premium tech minimalism,” or “museum-grade product photography” instead of naming a protected style or brand for imitation.

## Bio-Neon AI Core mode

Use this optional mode when the user asks for Master Flow, Digital Dreams, AI-agent visuals, intelligent systems, neural design, or a premium AI core aesthetic.

### Bio-Neon AI Core essence

Human perception meets artificial intelligence.

The look combines:

- eye / perception
- brain / thinking
- neural networks
- microchip / processing
- data streams / connection
- light core / insight
- glass, circuit boards, electric energy
- biological warmth and digital precision

### Color world

- cyan / turquoise: digital energy
- orange / copper: biological warmth
- gold: premium value
- magenta / rose: creative tension
- deep blue / violet: depth and contrast

### Visual feeling

Should feel like:

- laboratory + consciousness + AI core + premium motion design

Should not feel like:

- cheap robot
- generic cyberpunk
- code rain
- chaotic interface
- horror eye
- plastic brain

### Motion logic

Perception → thinking → processing → system → output

### Bio-Neon AI Core prompt template

Create a premium Bio-Neon AI Core visual identity: a fusion of human perception and artificial intelligence, centered around [subject]. Show [specific visual focus] with a luminous cyan-turquoise digital core, warm copper/orange biological accents, subtle gold premium highlights, and deep blue-violet background depth. Use layered glass surfaces, neural lines, microchip geometry, soft data streams, and controlled cinematic lighting. The composition should feel intelligent, calm, precise, premium, and alive. Avoid cheap robot clichés, generic cyberpunk, chaotic code rain, horror aesthetics, and plastic-looking anatomy.
